The Downsizing Parent Guide

A warm, step-by-step manual for helping a parent downsize — without the meltdowns, mystery boxes, or sibling World War III.

Use it like a friend explaining things: plain English, step by step, never condescending.

How to use this site

  • Read the chapters in order if you like linear comfort, or jump straight to what's on fire this week.
  • Print the worksheets — printable HTML pages with print-friendly styling.
  • Everything works offline; nothing here requires an account, tracked clicks, or data of any kind. It's a local-friendly static site.
