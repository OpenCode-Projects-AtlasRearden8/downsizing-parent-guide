# Room-Sort Worksheet (Printable)

> Print one per room per session. Tape it to the doorway. The 45-minute timer is more important than finishing the room — see [Room by Room](../02-room-by-room.md) for the four doors and the session plan.

```
ROOM: ______________________      SESSION #: _____    DATE: ____/____/____
SESSION PLAN (check one): □ cabinet days  □ flat surfaces  □ closet
                          □ decide pass   □ haul photos    □ full first pass
TIMER STARTED AT: ________    STOP-SIGNAL WORD: ______________________
```

---

## Session goals (pick no more than two)

- [ ] Whole room rough-sorted (stickers only, no debating)
- [ ] Decide pass on one color (green pile saved for last, always)
- [ ] At least one full drawer or shelf done *entirely*
- [ ] Furniture measured for the [floor plan](../05-floor-plan.md)
- [ ] One-box minimum: _______ boxes of true let-go actually left the house

## Safety / special-handling notes

- □ Medications set aside for [pharmacy take-back](../glossary.md) — treated separately
- □ Batteries/paint/chemicals flagged for county hazardous-waste drop-off
- □ Electronics: photos/drives checked *with parent* before wiping or donating
- □ Legal-ish papers found → "Ask a professional" pile, opened only with parent present
