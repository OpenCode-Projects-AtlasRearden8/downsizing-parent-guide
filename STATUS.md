# Project Status — The Downsizing Parent Guide

Last updated: 2026-11-05

## What was built

An emotionally-aware, beginner-friendly manual for helping a parent downsize:

- **Markdown manual (`docs/`)** — 9 documents covering the full arc:
  - `00-welcome.md` — how to use the manual, overwhelm-friendly mindset, scope disclaimer
  - `01-family-meeting.md` — seven sibling roles, 60-minute agenda, seven fair-talk scripts, stop-signal discipline, "Ask a professional" list
  - `02-room-by-room.md` — four-doors sorting, 45-minute session plan, staging zone, overwhelm emergency kit, top-down sort order
  - `03-heirloom-cards.md` — six-field decision cards plus a seven-card starter deck (including hard cases: contested heirlooms, "someday" items, white elephants, mystery boxes)
  - `04-donation-pickup.md` — charity shortlist, backward-scheduled pickups, booking/confirmation scripts, night-before prep, receipts and records
  - `05-floor-plan.md` — 9-measurement sweep, keeper inventory, graph-paper planning, diagonal depth, green/yellow/red furniture verdicts, mobility-aware planning
  - `06-estate-sale-vs-auction.md` — how each works, costs/fees in plain English, comparison table, vetting call scripts, hybrid strategy, DIY honesty note
  - `glossary.md` — plain-English definitions people + documents, sorting method, sales/money, logistics, safety/disposal
  - `worksheets/` — printable **Family-Meeting Agenda** and **Room-Sort Worksheet**
- **Static HTML site (`site/`)** — generated by `scripts/build.mjs` (a zero-dependency markdown→HTML generator): shared warm styling, top navigation with chapter/worksheet menus, prev/next links, print-friendly worksheet pages, education-only footer on every page
- **Tests (`tests/build.test.mjs`)** — 22 tests: converter units (escaping, links, tables, checkboxes, nested lists, blockquotes, code fences), page inventory, link-integrity, end-to-end content checks, and a guard test that unregistered pages fail the build
- **Housekeeping** — README (with LLC credit), MIT LICENSE with the exact required copyright line, `package.json` (build/test scripts, no dependencies)

## How to run it

```bash
npm run build     # docs/ + assets/ -> site/
npm test          # 22 tests, all passing
```

Then open `site/index.html` in any browser (fully offline; no server needed), or `npx serve site` if you prefer a local server. Node 18+ required; built and tested on Node 20.

## Known gaps

- The markdown converter is purpose-built for this site's dialect: it handles up to 4 heading levels, one level of list nesting, tables, blockquotes, fenced code and inline formatting — but not image pipelines, footnote syntax, or definition lists (none are in use)
- Prev/next navigation ordering is hardcoded in `MANUAL_ORDER` in `scripts/build.mjs`; adding a chapter requires updating that list (which the guard test enforces)
- Worksheets print from the browser; there is no PDF export
- Content-level gaps: no state-specific disposal/regulation details (intentional — explicitly delegated to local rules and professionals), no senior-community contract review guidance (out of scope: legal), no partnerships or live data for charities (kept evergreen on purpose)
- Site styling is embedded in each page (self-contained, offline-friendly); if you later split out a shared CSS file, `build.mjs` already supports copying extra assets from `assets/`
- `site/` is committed for local-first convenience; rebuild with `npm run build` after editing any `docs/` file
